# fuckwyy

一个由 GitHub Pages 托管页面、独立数据库保存共享计数的互动点击网站。黑红配色，支持手机和电脑。

- 11 张表情图，支持点击选择和随机切换。
- 点击大按钮、图片或按空格加一。
- 连击动画、可选音效、最高连击、今日点击和表情热力榜。
- 首页总数和表情热力榜由全站访客共同累计，数据写入托管 D1 数据库，每 5 秒读取更新。点击约每 0.7 秒批量提交；主总数显示服务器已确认的数值，待同步次数单独显示。
- 今日点击、个人历史和最高连击保留在浏览器 localStorage 中。清理浏览器数据会清空这些个人记录，但不会清空全站总数。
- 共享计数从升级后开始记录；旧版各浏览器中的本机次数不自动导入全站。
- 未确认点击保留在当前标签页的 sessionStorage 中，断网会自动重试，刷新可继续同步。关闭标签页前未同步的数据可能丢失。重复请求使用相同 ID，服务器只计一次。
- 无框架、无需安装依赖、无外部字体和统计脚本。

## GitHub Pages

仓库的 `main` 分支根目录作为发布来源；`.nojekyll` 禁用 Jekyll 处理。所有素材都使用相对路径，支持 `https://用户名.github.io/fuckwyy/` 和以后绑定的独立域名。

## 本地打开

在本目录运行 `python -m http.server 8080`，然后打开 `http://localhost:8080`。页面使用 ES 模块，不支持直接通过 file:// 打开。正式共享计数接口只允许已配置的网站来源；本地验证请使用隔离测试后端，不向正式计数写入测试数据。

## 共享计数接口

服务地址：`https://fuckwyy.ochre-gull-3398.chatgpt.site`。

- `GET /api/stats`：读取全站总数与表情热力榜，无缓存。
- `POST /api/click`：提交带唯一请求 ID 的点击批次；每批最多 100 次。
- `OPTIONS /api/click`：跨域预检。

允许的页面来源为 `https://mabucai.vip`、`http://mabucai.vip`、`https://mabucai.github.io`。以后绑定新域名时，需要同步更新后端允许的来源。

计数为无需登录的匿名娱乐功能，采用输入校验、数据库事务、请求去重和按浏览器标识限流。标识可重置，不提供严格反作弊保障。网页不包含数据库密钥或发布凭据。

## 修改

- `index.html`：页面文案和结构。

- `app.js`：点击、表情切换、音效和本机存档。

- `assets/`：图片资源，原始文件未被修改。
